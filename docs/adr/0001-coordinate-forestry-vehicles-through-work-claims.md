# Coordinate forestry vehicles through work claims

Forestry vehicle optimizations coordinate planters and harvesters through globally exclusive work claims scoped to vehicles from the same forestry tower, rather than persistent vehicle-to-vehicle escorts. Claims let actual work preempt speculative positioning, prevent vehicles from flocking to one target, and naturally move planters along a harvesting front; they are derived, non-saveable runtime state so AFD remains safely removable from saves. When an enabled tower-assigned vehicle has neither current nor future work, it performs a field wait at its current position instead of receiving a return-to-tower parking job. The claim registry and every vehicle or tree mutation are owned by the simulation thread; the main thread may only request setting changes and display synchronized state.
